## 数据来源

- `fixtures/checkout-service`：团队原创的最小样例仓，可公开复现。
- `evaluation/golden-cases.json`：团队构造的仿真案例，不来自企业生产数据。
- `knowledge/cases.json`：团队原创的 4 条历史案例种子，用于可复现 RAG，不来自真实事故库。
- 用户反馈、Issue、日志、指标、变更标识均为虚构示例，不含真实个人信息。
- 评测结果仅证明预定义工作流和安全策略符合预期，不等同于生产环境准确率或业务收益。

## HTTP Adapter 已实现但不夸大的接入层

六类 HTTP Provider、OpenAPI 3.1 契约和真实本地 HTTP 端到端烟测已实现。Bearer、关联头、超时、响应/请求限制、幂等重试、结构化错误和审批令牌隔离均由运行时代码执行。当前契约服务是本地 Stub，不是 GitHub、GitLab、Jenkins、Kubernetes 或云账号实测，详见 `docs/Adapter生产契约.md`。

## 复赛拟接入项

原生 GitHub/Git/Jenkins/Argo 连接器已实现，但本地证据不等于厂商账号运行。真实账号或生产集群接入时，仍必须在提交前补充：精确版本、许可证、API 费用、凭据范围、数据授权、脱敏方式、保留周期、替换方案和供应商锁定风险。连接器契约见 `config/platform-native.contract.json`。

## V0.6 原生平台连接器证据

`src/adapters/platforms.js` 只使用 Node.js 标准库、`git` 命令和 HTTP API，不新增 npm 依赖。连接器支持 GitHub Issues、Git、Jenkins 和 Argo Rollouts/Kubernetes；本地协议端点与真实 Git clone/commit/push/checkout、`node --test` 的 8/8 证据见 `reports/native-platform-smoke.json`。`Dockerfile.native` 在 Debian 12 上固定安装 Git 2.39.5；6/6 容器运行证据见 `reports/native-runner-smoke.json`。构建报告使用 USTC Debian 镜像是当前网络环境的可用镜像源，正式发布仍应固定基础镜像 digest 并在 CI 生成 SBOM/CVE 扫描。这些结果不是厂商账号、生产集群或公开缺陷集成绩。

公开评测 pilot 引用 SWE-bench 固定 dev Parquet，但不在交付包中再分发该文件。固定数据卡未显式声明 dataset license；pilot 仅保存快照 SHA-256、大小和单案例派生 test patch/日志。SWE-bench 软件仓库、SQLFluff base commit 与 pydicom base commit 均核验为 MIT。SQLFluff pilot 证明复现与同题调优链；pydicom 是模型调用前冻结的跨仓单次验证，终态为补丁契约失败。两者都不产生正式 DevOrbit 分数。

DevOrbit——多 Agent 研发闭环平台

## 作品简介（500 字以内）

DevOrbit 是一套自动处理线上缺陷的多 Agent 研发平台。用户提交问题、仓库和分支，系统读取 Issue、日志与代码，完成根因定位、补丁生成和独立测试；发布前等待负责人确认，最终交付代码 Diff、测试报告、审批/灰度记录和复盘知识卡。

系统基于本地实跑的官方 AgentTeams v1.2.2，由归并、影响、诊断、补丁、验证、发布、学习 7 个 Agent 协作；封装 7 个自定义 Skill、1 个官方日志查询 Skill 和 10 个 MCP Tool。Case State 与 Trace 串联上下文和执行证据，服务端强制最小权限、签名审批、幂等与回滚。

当前 Demo 在隔离样例仓完成 3 个失败到 4 项通过，支持审批暂停、续跑和灰度回滚。7 个闭环及 9 个对抗安全案例通过；失败按负例披露，不虚报收益。V0.9.6 在冻结的 30 案例 SWE-bench dev 基准上，闭环修复率 0%→10%（测试验证），补丁可应用率 0%→56%，三维消融与失败知识自沉淀可复核。

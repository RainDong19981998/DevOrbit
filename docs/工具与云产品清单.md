# 工具与云产品清单

## 当前可运行链路

| 层级 | 工具 / 能力 | 当前实现 | 调用与证据 | 权限 / 安全边界 | 真实系统替换路径 |
|---|---|---|---|---|---|
| 协同框架 | AgentTeams v1.2.2 | 8 个 Worker CR、1 个 Team CR、7 个 Worker ZIP、两阶段部署脚本 | `config/agentteams.yaml`、`reports/agentteams-contract.md` | MCP 地址部署时强制显式配置；当前未启动官方集群 | `MCP_URL=... npm run deploy-agentteams` |
| Issue / 反馈 | Issue Adapter | MCP `issue.fetch_signals` 从团队构造 Fixture 读取 Issue 与用户反馈 | Tool audit、Case/Trace、稳定信号 ID | L0 只读；坏输入隔离 | 替换 Handler 为 GitHub/GitLab/Jira/企业工单 API |
| 日志 / 指标 / 变更 | Observability Adapter | MCP `observability.fetch_signals` 从 Fixture 读取日志、指标和变更 | Tool audit、时间线、证据引用 | L0 只读；当前不调用云账号 | 接入 SLS、OpenTelemetry 或现有可观测平台 |
| 官方云 Skill | alibabacloud-sls-query v0.0.2 | 合规裁剪快照随 Intake/RCA Worker 分发；核心 `SKILL.md` 未修改 | 门户/分发摘要、Worker ZIP 内容、140/140 契约检查 | 仅 `GetIndex`、`GetLogsV2`；无 CLI/凭据/权限即停止 | 显式配置 SLS project、logstore 和运行时角色后启用 |
| 代码仓 | Repository Adapter | 读取样例仓、建立隔离工作区、写入最小补丁、销毁工作区 | 文件摘要、写操作审计、路径逃逸测试 | 读取 L0；写入仅 L1 沙箱；目录白名单 | 替换为 Git Provider / 代码托管平台 API |
| CI / 测试 | CI Adapter | MCP `ci.run_tests` 执行白名单 `node --test` | 3 failed → 4 passed、退出码、SHA-256 制品 | 仅隔离工作区；失败即阻断发布 | 替换为 Jenkins/GitHub Actions/GitLab CI 等 |
| 发布 | Release Adapter | MCP `release.canary` 执行确定性灰度判定与回滚分支 | 审批号、幂等键、灰度前后指标、回滚记录 | L2 强制人工审批；L3 禁止自动执行 | 接入 Kubernetes/发布平台，保留同一策略契约 |
| 知识库 | Knowledge Adapter | MCP 检索 4 条团队构造案例并写回复盘卡 | Top-3 分数、`knowledge://` 引用、写回审计 | 只引用有效证据；写入前脱敏 | 替换为向量库/数据库，保持引用与 Schema |
| 协议 | MCP 2025-06-18 | 自研 JSON-RPC Streamable HTTP 基本实现 | `initialize`、会话、发现、调用、幂等、错误与销毁冒烟 | Origin 校验；生产需网关鉴权与限流 | 端点保持 `/mcp`，Adapter Handler 可替换 |
| 本地运行 | Node.js 20+ | HTTP 服务、测试、评测、报告生成；无第三方 npm 包 | `npm run verify-all`、可回放报告 | 无外部密钥、数据库或网络运行依赖 | 容器或 AgentTeams Worker 运行时 |

## 选择原则与迁移成本

- 当前初赛用 Fixture/Mock 保证评委无需账号即可复现，但补丁和测试在隔离样例仓中真实执行。
- Skill 只承载稳定能力，外部系统差异收敛在 MCP Adapter Handler；替换平台不改变 Case State、策略和 Worker 协议。
- 真实凭据不进入 Worker 上下文；生产由网关或运行时角色注入短期、最小范围凭据。
- 当前未使用商业 API、闭源模型和外部数据库。真实接入时逐项披露版本、许可证、费用、权限、数据授权和替换成本。

# 自动解说视频说明

`deliverables/DevOrbit_初赛讲解视频_自动语音版.mp4` 是提交备份版讲解视频：

- 画面由最终方案 PDF、真实浏览器/API 工程录屏组成；
- 普通话音轨由本机开源 eSpeak NG 经 Speech Dispatcher 离线生成，无外部 API、账号或费用；
- 视频包含短字幕，覆盖场景、架构、七个 Worker、根因证据、真实 Red→Green、审批、灰度、回滚、知识沉淀、官方 Skill 和验证指标；
- 真实浏览器片段沿用 `DevOrbit_演示视频.mp4`，其业务请求、测试和审批续跑均调用同一 Demo API；
- 案例和指标为团队构造仿真；当前未声称启动官方 AgentTeams 集群或调用云账号。
- 自动语音版已按 V0.6.0 口径重建，包含 29/29 单元测试和原生连接器证据；主工程录屏也已按 V0.6.0 重新录制并完成抽帧复核。

自动语音可作为官网讲解视频备份。正式提交前若条件允许，建议按 `docs/演示脚本.md` 录制真人配音并替换本文件，以提升表达自然度；替换后需重新运行 `npm run finalize-submission` 并更新视频人工复核摘要。

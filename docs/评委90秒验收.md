# 评委 90 秒验收

## 1. 一条命令看真实性（约 15 秒）

环境：Node.js 20+，无需密钥、数据库或安装第三方 npm 包。

```bash
npm run verify-all
```

预期证据：29 项单元测试全绿；7/7 闭环案例、5/5 安全分支、4/4 RAG Top-1、6/6 对抗安全案例、原生平台连接器 8/8、native runner 6/6 通过；AgentTeams v1.2.2 资源/包/Skill 契约 140/140、Adapter OpenAPI 契约 66/66、SWE-bench dev pilot 1 个真实失败复现（0 个 DevOrbit 分数）、MCP 2025-06-18、OTLP 与内容合规扫描通过。

Docker 可用时再运行生产门禁：

```bash
npm run container-smoke
```

预期证据：14/14 运行时断言通过，并确认 UID 10001、只读根文件系统、cap-drop ALL、no-new-privileges、健康检查、控制面鉴权和同 Case/Trace 审批续跑。

## 2. 一次操作看完整闭环（约 45 秒）

```bash
npm start
```

打开 `http://127.0.0.1:4173`，点击“运行完整案例”。观察 7 个 Worker 的协同轨迹、91% 根因及引用、补丁前 3 项失败、补丁后 4 项通过。系统会停在 L2 门禁；点击“批准 10% 灰度”后，从同一 Case/Trace 继续到确认放量和知识写回。完整成功路径包含 10 个 MCP Tool、15 次 `tools/call` 审计。

无需手动操作的录制入口：`http://127.0.0.1:4173/?demo=happy-path`。它只用于演示录制，仍调用同一 API、测试门禁和审批续跑。

切换“根因低置信停止”“真实测试失败阻断”“灰度退化自动回滚”，可现场验证 fail-closed 分支。

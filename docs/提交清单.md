# 复赛最终提交清单（V1.0.0）

初赛提交日期 2026年8月16日；复赛最终版 V1.0.0 于 2026年8月31日冻结，**提交截止 2026年9月3日 18:00**，最终以官网/组委会最新通知为准。

## 官网必交

- 项目名称：`DevOrbit——多 Agent 软件研发闭环引擎`
- 作品简介：使用 `docs/作品简介.md` 正文，保持 500 字以内。
- 作品附件：上传 `deliverables/DevOrbit_复赛提交总包.zip`；方案 PDF 已包含在总包内。
- 粘贴入口：按 `docs/官网提交粘贴稿.md` 填写，避免现场改写造成指标或版本口径不一致。

## 强烈建议一并提交

- 可执行代码包：`deliverables/DevOrbit_复赛可执行代码包.zip` 已嵌入总包；仅在平台另开代码包字段时单独上传。
- AgentTeams Worker 包：运行 `bash scripts/package_workers.sh` 后检查 `worker-packages/dist/` 的 7 个 ZIP。
- AgentTeams 运行证据：运行 `npm run validate-agentteams-runtime` 检查冻结报告 18/18，并确认 `reports/agentteams-contract.md` 为 140/140。表述为“官方 AgentTeams v1.2.2 本地实跑”，不要写成云账号、厂商平台或生产集群实测。
- 仓库链接：将代码包推到可被评审访问的 Git 仓库后填写；不要提交不可访问或需要临时授权的地址。
- 工程证据短片：`deliverables/DevOrbit_演示视频.mp4`（129 秒 ≤8 分钟门禁，含 Agent 协作/Skill 调用证据/异常处理演示三要素），由真实浏览器和 API 自动录制，可用 `npm run record-demo` 重建。
- Demo 讲解视频：`deliverables/DevOrbit_演示视频_语音讲解版.mp4`（CosyVoice 旁白版，供路演使用）。
- PPTX 备份：`deliverables/DevOrbit_复赛方案.pptx`（18 页 V1.0.0，含初赛反馈标红对比/场景闭环图/风险边界声明/可复制性四项必含）
- 公开复现证据：`deliverables/DevOrbit_公开基准复现试点.pdf`，含真实本地模型 Run 1–11 调优链，以及预注册跨仓 pydicom 单次验证；后者在补丁契约处失败并按负例披露，正式 benchmark 仍为 `not_run / 0 cases`。
- V1.0.0 新证据（已含于代码包）：`reports/scenario-migration.json`（场景迁移）、`reports/fault-drill.json`（故障演练 6/6）、`reports/skills-registry.json`（Skill 注册表）、`src/runtime/state-store.js`（状态持久化）。

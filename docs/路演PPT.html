03 / CONTROL PLANE

高风险动作，默认停在门禁前

权限与审批

L0 只读 · L1 沙箱 · L2 签名审批+灰度 · L3 只出方案
Manager 签发 Case/Action/时效受限的 HMAC 回执，Release Worker 只能消费，MCP 服务端二次验签。策略门禁由确定性代码执行，不由模型绕过。

incident → 信号 → git SHA → patch → 测试 → HMAC 审批 → 灰度指标 → Episode，链式 sha256 逐环绑定。npm run verify-evidence-chain 独立复核，篡改任一环节立即可检出。9/9 对抗案例 fail closed。

13 / WHY NOT

为什么不是单 Agent，也不是固定工作流

单 Agent

上下文集中、权限过宽；生成与验证同源偏差。

固定工作流

可控但难处理证据冲突；低置信只能停机等待。

DevOrbit

Leader 动态委派与补证决策；Worker 最小权限、独立验证；失败带反馈自主返工；策略门禁不由模型绕过。

DevOrbit职责隔离 · 独立验证 · 动态停止条件

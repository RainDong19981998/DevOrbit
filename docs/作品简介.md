# 作品简介（500 字以内）

> 复赛最终版 V1.0.0：2026年8月31日

**项目名称：DevOrbit——多 Agent 研发闭环平台**

用户提交问题、仓库和分支，系统读取 Issue、日志与代码，完成根因定位、补丁生成和独立测试；发布前等待负责人确认，最终交付代码 Diff、测试报告、审批/灰度记录和复盘知识卡。

系统基于本地实跑的官方 AgentTeams v1.2.2，由归并、影响、诊断、补丁、验证、发布、学习 7 个 Agent 协作；封装 7 个自定义 Skill、1 个官方日志查询 Skill 和 14 个 MCP Tool。Case State 与 Trace 串联上下文和执行证据，服务端强制最小权限、签名审批、幂等与回滚。

V1.0.0 新增状态持久化与重启恢复（崩溃后审批续跑）、Skill 版本溯源（每次运行记录版本与摘要）与第二类场景迁移（结算→库存，机制零改动双域闭环）；故障演练 6/6、单测 113/113、对抗安全 9/9 通过。在冻结的 30 案例 SWE-bench dev 基准上，闭环修复率 0%→10%、补丁可应用率 0%→56%，三维消融与失败知识自沉淀可复核；失败按负例披露，不虚报收益。

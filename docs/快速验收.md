# 快速验收

## 1. 一条命令看真实性（约 15 秒）

环境：Node.js 20+，无需密钥、数据库或安装第三方 npm 包。

```bash
npm run verify-all
```

预期证据：113 项单元测试全绿；7/7 闭环案例、5/5 安全分支、4/4 RAG Top-1（词法+混合）、9/9 对抗安全案例、原生平台连接器 8/8 通过；官方 AgentTeams v1.2.2 本地运行报告 18/18、资源/包/Skill 契约 141/141、Adapter OpenAPI 契约 66/66；同题模型 Run 1–11 失败证据 39/39，跨仓独立负例证据 26/26；MCP 双版本、OTLP 与内容合规扫描通过。平台级证据：deepseek-v4-flash-0731 自主协同 18 条响应（`reports/agentteams-autonomous-probe.json`）、GitLab CE 真实自愈 e2e 17/17（`reports/gitlab-e2e-self-healing.json`）、Docker 灰度 8/8（`reports/canary-docker.json`）、30 案例 SWE-bench 公开基准正式计分 120+ runs（`reports/public-benchmark.json`）。

V1.0.0 新增验收点：**状态持久化与重启恢复**（`src/runtime/state-store.test.js` 5 项：快照原子写/损坏隔离/重启后审批续跑同 case/trace/证据链连续）；**第二类场景迁移**（`npm run scenario-migration`：结算→库存机制序列完全一致、双域 3 失败→4 通过闭环，`reports/scenario-migration.json`）；**可靠性故障演练 7/7**（`npm run fault-drill`：返工熔断/模型 429 重试/500 fail-closed 不泄露密钥/工具错误审计/DB 门禁/端点不可达，`reports/fault-drill.json`）；**Skill 版本溯源**（8 Skill SemVer+sha256 注册表 `reports/skills-registry.json`，trace 记录 skillVersion/skillDigest）。

V0.9.6 公开基准（edit-based 补丁引擎，同冻结 test split）：**devorbit 闭环率 0%→10%（3/30，均为真实闭环修复），补丁可应用率 0%→56%，RCA Top-3 73.3%**；single-agent 同模型同预算 0/30 闭环。三维消融可复核：管道维度（diff-based V0.8 归档 0% vs edit-based）、模型维度（glm / deepseek-v4-flash-0731 / 本地 qwen3:8b）、架构维度（devorbit vs single-agent），见 `reports/model-ablation.md`。失败知识自沉淀：42 条 negative Episode 自动生成（`knowledge/benchmark-episodes.json`），第二轮运行按仓库召回警示注入 patch 提示。

Docker 可用时再运行生产门禁：

```bash
npm run container-smoke
```

预期证据：14/14 运行时断言通过，并确认 UID 10001、只读根文件系统、cap-drop ALL、no-new-privileges、健康检查、控制面鉴权和同 Case/Trace 审批续跑。

## 2. 一次操作看完整闭环（约 45 秒）

```bash
npm start
```

打开 `http://127.0.0.1:4173`，点击“运行完整案例”。观察 7 个 Worker 的协同轨迹、91% 根因及引用、补丁前 3 项失败、补丁后 4 项通过。系统会停在 L2 门禁；点击“批准 10% 灰度”后，从同一 Case/Trace 继续到确认放量和知识写回。完整成功路径包含 10 个 MCP Tool、15 次 `tools/call` 审计。

无需手动操作的录制入口：`http://127.0.0.1:4173/?demo=tour`（129 秒导览模式，自动跑完整案例并滚动展示门禁、灰度、证据链、Skill 版本溯源与基准大盘，含 Skill 调用证据与异常处理演示分镜，底部烧录中文字幕）。`?demo=happy-path` 仍保留为单场景录制入口。两者均调用同一 API、测试门禁和审批续跑。语音讲解版由 `scripts/build_narration.py`（CosyVoice v3-flash）生成旁白并经 `scripts/record_demo.sh` 混音。

切换“根因低置信停止”“真实测试失败阻断”“灰度退化自动回滚”，可现场验证 fail-closed 分支。

## 环境与复现

可审计环境为 Ubuntu 22.04、Python 3.10.12、SQLFluff 0.4.1、pytest 6.2.5、packaging 21.3，其余版本见 `evaluation/public-pilot/sqlfluff__sqlfluff-884/requirements.lock`。SQLFluff 0.4.1 分类器只列到 Python 3.9，因此 Python 3.10.12 是已披露偏差；它已在两个干净依赖目录中复现完全相同的业务断言，不是导入、安装或 collection 失败。

离线核验仓库证据：

```bash
npm run validate-public-pilot
```

联网下载固定源码、核验 archive/LICENSE 摘要、重建依赖并复现 baseline：

```bash
npm run reproduce-public-pilot
```

重放脚本只访问 base 源码和公开 test patch，不读取 gold patch。正式多方法评测仍须扩充到预注册的 repository-grouped validation/test 集，冻结 Agent 配置后才运行 test，并按 Wilson、paired bootstrap 和 McNemar 协议报告。

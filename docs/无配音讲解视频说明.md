# 无配音讲解视频说明

`deliverables/DevOrbit_初赛讲解视频_无配音版.mp4` 是 2026年8月16日初赛提交版讲解视频：

- 视频只有 H.264 画面流，不包含任何音轨；
- 画面由最终方案 PDF、真实浏览器/API 工程录屏和底部字幕组成；
- 字幕覆盖场景、宏观方案、四层架构、七个 Worker、根因证据、真实 Red→Green、审批、回滚、知识沉淀、Skill 和验证指标；
- 浏览器片段沿用 `DevOrbit_演示视频.mp4`，其业务请求、测试和审批续跑均调用同一 Demo API；
- 案例和指标为团队构造仿真；视频展示官方 AgentTeams v1.2.2 本地运行证据，但不声称调用云账号、厂商平台或生产集群。

重建命令为 `npm run build-explainer`。重建后必须使用 `ffprobe` 确认讲解视频和工程演示视频都不存在 `audio` stream，并重新运行发布审计。
